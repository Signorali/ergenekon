Gereksinimler — Kuruluma başlamadan önce

  • Docker Desktop kurulu ve çalışıyor olmalı
    Sürüm 4.0 veya üzeri · Windows, Linux ve macOS desteklenir · docker.com/get-started adresinden indirilebilir
  • Proje klasörü hazır olmalı
    Tüm sistem dosyaları tek bir klasörde bulunmalıdır (örn. E:\Entegre sistem) · docker-compose.yml bu klasördedir
  • 80, 443, 4443 portları boş olmalı
    Bu portları kullanan başka bir uygulama çalışıyorsa .env dosyasından değiştirilebilir (PROXY_HTTP_PORT, PROXY_HTTPS_PORT, PROXY_OTUKEN_PORT)
💡
Minimum sistem gereksinimi: 4 GB RAM, 10 GB disk. PostgreSQL + Redis + 6 container aynı anda çalışır.
2

İlk Kurulum — Sadece 3 komut

✅
Sertifika üretimi, veritabanı migrasyonları ve servis başlatma otomatik gerçekleşir. Herhangi bir araç kurmana gerek yok.
# 1. Proje klasörüne gir
cd "E:\Entegre sistem"

# 2. Sistemi başlat (ilk seferde 3-5 dakika sürer)
docker-compose up -d

# 3. Tüm servislerin çalıştığını doğrula
docker-compose ps
  • docker-compose up -d çalıştır
    İlk seferde Docker imajları indirilir ve derlenir · cert-init servisi otomatik SSL sertifikası üretir · Veritabanı şeması otomatik kurulur
  • docker-compose ps ile durum kontrol et
    Tüm servislerin durumu Up olmalı · cert-init servisi Exited (0) gösterirse normaldir — görevini tamamlayıp kapandı demektir
  • nginx/certs/ klasöründe ca.crt dosyasını bul
    Bu dosya sertifika aktivasyonu için gereklidir · Bir sonraki adımda kullanacaksın
⚠️
İlk kurulumda tarayıcı güvenlik uyarısı gösterir. Bu normaldir — sertifikayı sisteme tanıtmadan önce geçici bir durumdur. Bölüm 3'teki adımları uyguladıktan sonra uyarı tamamen kaybolur.

Sertifika Aktivasyonu — Sadece bir kez yapılır

Tarayıcının kilit ikonunu yeşil göstermesi için CA sertifikasını işletim sistemine tanıtman gerekir. Bu işlem format sonrası da tekrarlanır — ama her başlatmada değil, sadece yeni bir makineye kurarken.

🪟 Windows
  1. Dosya Gezgini'ni aç
  2. nginx\certs\ klasörüne git
  3. ca.crt dosyasına çift tıkla
  4. "Sertifikayı Yükle" butonuna tıkla
  5. Depo: "Yerel Makine" seç → İleri
  6. "Tüm sertifikaları aşağıdaki depoya yerleştir" seç
  7. "Güvenilen Kök Sertifika Yetkilileri" seç
  8. Son → Evet → Tamam
  9. Tarayıcıyı tamamen kapat ve yeniden aç
🐧 Linux (Ubuntu / Debian)
  1. Terminal aç
  2. Proje klasörüne git
  3. Aşağıdaki komutları çalıştır:
sudo cp nginx/certs/ca.crt \
  /usr/local/share/ca-certificates/
sudo update-ca-certificates
Chrome için ekstra: chrome://settings/certificates → Authorities → Import → ca.crt
🔒
Aktivasyon sonrası tarayıcı adres çubuğunda kilit ikonu görünmelidir. "Bağlantı güvenli değil" uyarısı tamamen kaybolur. Firefox için tarayıcının kendi sertifika deposuna ayrıca ekleme gerekebilir.

Not: Üretilen sertifika 10 yıl geçerlidir. Süre dolduğunda nginx/certs/ klasörünü sil ve docker-compose up -d komutunu tekrar çalıştır — yeni sertifika otomatik üretilir.

Günlük Kullanım Komutları

İşlem Komut Not
Sistemi başlat docker-compose up -d Tüm servisler arka planda çalışır
Sistemi durdur docker-compose down Veriler korunur, sadece containerlar durur
Servis durumu docker-compose ps Tüm servislerin durumu listelenir
Logları izle docker-compose logs -f Ctrl+C ile çıkılır, veriler silinmez
Belirli servis logu docker-compose logs -f umay-backend umay-backend, otuken-backend vb.
Yeniden başlat docker-compose restart Tüm servisleri yeniden başlatır
Güncelle & yeniden başlat docker-compose up -d --build Kod değişikliği sonrası imajları yeniden derler
🔄
Bilgisayar yeniden başlatıldıktan sonra: Docker Desktop açıksa sistem otomatik çalışmaya devam eder (restart: unless-stopped ayarı aktif). Docker Desktop açık değilse docker-compose up -d komutunu çalıştır.

Sorun Giderme

❓ Tarayıcı hâlâ güvenlik uyarısı gösteriyor
Sertifika aktivasyonu doğru yapılmamış olabilir. Bölüm 3'teki adımları tekrar dene. Windows'ta "Güvenilen Kök Sertifika Yetkilileri" deposuna eklendiğinden emin ol. Ardından tarayıcıyı tamamen kapat (tray ikonundan çık) ve yeniden aç. Firefox kullanıyorsan: Ayarlar → Gizlilik → Sertifikaları Görüntüle → Yetkililer → İçe Aktar.
❓ "Port zaten kullanımda" hatası alıyorum
80, 443 veya 4443 portu başka bir uygulama tarafından kullanılıyor. .env dosyasına şu satırları ekleyerek port değiştir:
PROXY_HTTP_PORT=8080  ·  PROXY_HTTPS_PORT=8443  ·  PROXY_OTUKEN_PORT=8444
❓ cert-init servisi hata verdi, sertifikalar oluşmadı
nginx/certs/ klasörünü sil ve tekrar dene: docker-compose up -d. Log için: docker-compose logs cert-init.
❓ Bir servis "Exited" durumunda görünüyor
Servis loglarını kontrol et: docker-compose logs <servis-adı>. Çoğunlukla veritabanı bağlantısı gecikmesinden kaynaklanır — birkaç dakika bekleyip docker-compose restart <servis-adı> yeterlidir.
❓ Sistemi tamamen sıfırlamak istiyorum
Dikkat: Aşağıdaki komut tüm verileri siler.
docker-compose down -v → Tüm containerlar ve volume'lar silinir. Ardından docker-compose up -d ile temiz kurulum başlatılır.
